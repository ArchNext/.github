# ArchNext

Organisation regroupant nos serveurs MCP, outils d'automatisation et projets internes.

## Sécurité & qualité

- Dependabot (alertes + mises à jour automatiques) sur tous les dépôts
- Secret scanning + push protection et CodeQL sur les dépôts publics
- Dependency review sur chaque PR des dépôts publics
- CI automatisée (GitHub Actions)

Une vulnérabilité ? Voir notre
[politique de sécurité](https://github.com/ArchNext/.github/blob/main/SECURITY.md).
